# Guía del Host

El Host no necesita cuenta de Google ni acceso a Sheets o Apps Script.

## Primer ingreso

1. Abre la dirección `/host` entregada por el Superhost.
2. Inicia sesión con tu usuario y contraseña temporal.
3. Crea una contraseña nueva de al menos 12 caracteres.
4. Selecciona hotel, sede y actividad entre las asignaciones disponibles.
5. Pulsa **Load Activity**.

## Antes del evento

1. Comprueba fecha, hora, duración, transición y recurrencia.
2. Decide si las solicitudes se abren antes de comenzar.
3. Activa o desactiva **Show Public Status** según lo autorizado.
4. Copia el enlace público o descarga el QR del hotel.
5. Comprueba que el Bridge correcto esté en línea y conectado a VirtualDJ.

## Durante el evento

1. Pulsa **Start** cuando comience realmente la actividad.
2. Usa **Open Requests** o **Close Requests** sin reiniciar el reloj.
3. Respeta el orden de llegada y la hora final estimada.
4. Revisa comentarios y dedicatorias visibles en cada solicitud.
5. Finaliza con **Finish**. La cola se conserva para consulta.

## Acciones destructivas

`Start New` y `Archive & Clear` muestran confirmación porque crean un ciclo nuevo
o archivan la cola actual. No los uses para abrir/cerrar solicitudes.

Las opciones visibles dependen de los permisos asignados por el Superhost. Un
Host nunca puede cambiar el hotel de una petición para acceder a otro tenant.

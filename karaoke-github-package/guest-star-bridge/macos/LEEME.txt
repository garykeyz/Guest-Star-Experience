GUEST STAR BRIDGE 4.0.1 UNIVERSAL PARA MAC

Compatible con Mac Intel y Apple Silicon M1, M2, M3, M4 y M5.

1. Mueve Guest Star Bridge.app a Aplicaciones.
2. La primera vez, haz clic derecho sobre la app y selecciona Abrir.
3. Inicia sesión con la cuenta Host creada por el Superhost.
4. Selecciona el hotel, sede y actividad asignados.
5. Lee GUIA-MAC-SOLO-BRIDGE.txt para configurar VirtualDJ y la biblioteca.

No necesitas la cuenta Google, Sheets, Apps Script, Node, npm ni Terminal.
Las credenciales del Bridge se guardan en macOS Keychain.

La aplicación recibe solicitudes, muestra comentarios, reconcilia la cola real
de VirtualDJ, calcula tiempos exactos y respeta el idioma de cada canción.

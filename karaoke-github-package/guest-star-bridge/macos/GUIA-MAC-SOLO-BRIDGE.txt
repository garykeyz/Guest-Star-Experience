GUEST STAR BRIDGE 4.0.1 — GUÍA PARA LA MAC DEL DJ

Esta guía es para una persona que operará Bridge + VirtualDJ en otra Mac.
No necesita la cuenta Google del Superhost, Google Sheets ni Apps Script.

COMPATIBILIDAD

- Mac Intel o Apple Silicon M1, M2, M3, M4 y M5.
- macOS 11 Big Sur o posterior.
- No necesitas instalar Node, npm ni usar Terminal.

LO QUE EL SUPERHOST DEBE ENTREGAR

1. APP ZIP o DMG oficial 4.0.1.
2. Dirección del panel Host, por ejemplo https://host.gstarxp.com/host.
3. Usuario Host y contraseña temporal.
4. Nombre del hotel, sede y actividad asignados.
5. Puerto y contraseña de Network Control, si existe.

PASO 1 — INSTALAR

1. Cierra cualquier Bridge anterior.
2. Descomprime el ZIP o abre el DMG.
3. Mueve Guest Star Bridge.app a Aplicaciones.
4. Usa clic derecho sobre la app → Abrir → Abrir.
5. Si macOS la bloquea, ve a Ajustes → Privacidad y seguridad → Abrir de todos modos.

PASO 2 — PREPARAR VIRTUALDJ

1. Abre VirtualDJ.
2. Ve a Settings → Extensions.
3. Instala Network Control si falta.
4. Actívalo y anota puerto y contraseña.
5. Mantén VirtualDJ abierto durante el evento.

PASO 3 — INICIAR SESIÓN Y ELEGIR ACTIVIDAD

1. Abre Guest Star Bridge.
2. Confirma que la pantalla de acceso muestre v4.0.1.
3. Escribe el usuario y contraseña temporal entregados por el Superhost.
4. Crea una contraseña nueva cuando se solicite.
5. Selecciona únicamente el hotel, sede y actividad asignados.
6. Autoriza esta Mac como dispositivo cuando se solicite.

PASO 4 — CONECTAR LA BIBLIOTECA

1. Conecta el disco antes de abrir el evento.
2. En Settings, selecciona la carpeta principal de karaoke.
3. Activa recordar carpetas solo si esta Mac es segura.
4. Escribe el mismo puerto y contraseña de Network Control.
5. Guarda, prueba VirtualDJ y espera el primer escaneo.

PASO 5 — PRUEBA COMPLETA

1. Pulsa Synchronize.
2. Abre el enlace público del hotel desde otro celular.
3. Envía una canción de prueba.
4. Confirma que aparezca en Bridge.
5. Agrégala y comprueba la cola Karaoke real de VirtualDJ.
6. Retira o archiva la prueba.

PASO 6 — EVENTO

1. Confirma internet, disco, biblioteca y VirtualDJ.
2. Pulsa Start Activity únicamente al comenzar.
3. Abre o cierra Requests según indique el Host.
4. Respeta número de llegada, acumulado, turno y hora final.
5. Usa Completed o Skipped con confirmación.
6. Si fue accidental, usa Undo y restaura en la posición anterior, al final o fuera.

IMPORTANTE

- Bridge, VirtualDJ y biblioteca deben estar en la misma Mac.
- La cuenta Google, Apps Script y las hojas permanecen en la nube del Superhost.
- No compartas tu contraseña ni autorices una Mac ajena.
- Usa un solo Bridge activo por actividad.
- Si esta Mac deja de usarse, pide al Superhost que revoque el dispositivo.

MIGRACIÓN 3.X

La URL /exec y el PIN aparecen solo como opciones avanzadas para una migración.
Una instalación 4.0 normal usa usuario Host y token de dispositivo; no debes
pedir acceso a la cuenta Google.

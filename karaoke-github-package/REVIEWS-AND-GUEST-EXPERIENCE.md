# Reseñas y experiencia del huésped

Los módulos de reseña, recordatorio y seguimiento son opcionales y se configuran
por hotel.

## Identidad y mensajes

El Superhost puede definir nombre del equipo, lema, bienvenida, mensaje en vivo
y mensaje final, además de decidir qué elementos aparecen en la página pública.

## Reseña interna

- Puede ser anónima.
- Nombre, correo y comentario son opcionales.
- La calificación nunca bloquea otra solicitud.
- El Host con permiso puede consultar, archivar o eliminar reseñas.

## Reseña externa

El enlace a Google, TripAdvisor u otro proveedor es independiente de la reseña
interna. Nunca se exige completar una para mostrar la otra.

## Consentimiento

No se guarda un contacto ni se envía un mensaje si la persona no marcó el
consentimiento correspondiente. Los recordatorios y seguimientos se deduplican,
incluyen baja y respetan el hotel y la actividad seleccionados.
